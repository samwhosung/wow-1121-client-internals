# WoW 1.12.1 Client Internals (archived)

This repository is archived. Its successor is
**[benilla-re](https://github.com/samwhosung/benilla-re)**, the same reverse engineering of the
World of Warcraft 1.12.1 client (`WoW.exe`, build 5875), read again at the bytes. It has a symbol
table of every function, global and struct field, a doc per system, the data tables, and checks
that run against your own copy of the exe. It takes contributions.

The chapters under `docs/` are kept here as they were and are no longer maintained. Where one
disagrees with benilla-re, benilla-re is right.
